# nidora-site — le web de Nidora sur `nidora.lv-dev.eu`

Pages légales et point d'entrée web de Nidora. Le texte des documents légaux a
sa **source de vérité dans le dépôt de l'application** (`nidora-app/docs/legal/`) ;
ce dépôt ne porte que le rendu publié (pandoc) et la mise en ligne GitHub Pages.

Le contenu publié ici est volontairement public : une politique de
confidentialité et des CGU doivent être consultables par tout parent.
Rien d'opérationnel ne vit dans ce dépôt — pas de clé, pas de runbook
d'infrastructure. L'exploitation (DNS, Resend, Supabase) est documentée
en privé, côté dépôt de l'application.
